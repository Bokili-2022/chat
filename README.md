# Real-Time Chat Application

A lightweight, real-time web chat application built entirely with **Vanilla JavaScript**, HTML5, and CSS3. 

## Features
* **Live Chat Messaging** – Send and receive messages instantly.
* **Status Notifications** – Real-time updates when users join, leave, log out, or reconnect.
* **Clean UI** – Simple, modern, and responsive chat interface.

## Technologies Used
* **Frontend:** Vanilla JavaScript (ES6+), HTML5, CSS3
* **Backend:** PHP
* **Web Server:** Nginx

## Prerequisites
To run this application locally, you will need:
* An **Nginx** web server configured to serve PHP.
* **PHP 8.x** (or lower) installed on your machine.

## Getting Started

To run this project locally, simply clone the repository and open the `/chat/` path in your browser.

```bash
# Clone the repository
git clone https://github.com

# Navigate to the project folder
cd chat
```
